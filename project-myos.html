MyOS

A desktop interface with windows, a dock, and an iPod player.

RoleFrontend
StackNext.js, React
FocusWindows, dock, player
ByMuhammad Rehan Kamboh

Overview

MyOS is a browser-based desktop shell: draggable windows, a dock, and an iPod-style music player with a real local video path on the LCD — not a YouTube embed.

Built with Next.js and React. The Music app opens the iPod; song select shows a loading state, then plays on the device screen.
