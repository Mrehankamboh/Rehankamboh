# Muhammad Rehan Kamboh — Portfolio Template

Premium Framer-style personal portfolio for **Muhammad Rehan Kamboh**. Vanilla HTML, CSS, and JS.

**Live reference portfolio:** https://rehankamboh.vercel.app/

## Run locally

```bash
cd vera-portfolio
npx serve -l 4174 .
```

Open [http://localhost:4174](http://localhost:4174).
